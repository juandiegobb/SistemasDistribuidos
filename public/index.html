Guía de Integración & Comandos

Usa estos comandos en tu terminal de PowerShell o CMD para conectar servidores y enviar mensajes al Middleware:

1

Iniciar un miniServer local (Servidor nodo)

Inicia un servidor en el puerto 4000 con el nombre 'ServerJuan' y se conecta automáticamente al Middleware:

node miniServer.js 4000 ServerJuan
2

Iniciar múltiples servidores simultáneos

Abre otra terminal para correr otro nodo en paralelo:

node miniServer.js 4001 ServerMaria
3

Enviar mensaje desde la terminal (`/messages`)

curl -X POST http://localhost:3000/messages -H "Content-Type: application/json" -d "{\"sender\": \"ServerJuan\", \"message\": \"¡Hola desde mi servidor!\"}"
4

Enviar mensaje dirigido (`/send-message/:name`)

curl -X POST http://localhost:3000/send-message/ServerJuan -H "Content-Type: application/json" -d "{\"sender\": \"Cliente_01\", \"message\": \"Tarea distribuida completada\"}"
5

Enviar Heartbeat manual

curl -X POST http://localhost:3000/heartbeat/ServerJuan
